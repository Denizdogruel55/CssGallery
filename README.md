# 🖼️ Resim Galerisi (HTML + CSS)

Bu proje, **HTML5** ve **CSS3** kullanılarak geliştirilmiş bir **Resim Galerisi**dir.  
Projede **Flexbox** yapısı kullanılmış ve resimler düzenli bir şekilde hizalanmıştır.
